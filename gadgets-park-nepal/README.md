# Gadgets Park Nepal

Premium gadgets e-commerce frontend — iPhones, MacBooks, Android phones, iPads & smartwatches. Browse online, order via WhatsApp or Instagram.

## Stack

- **Next.js 15** (App Router, static generation)
- **Tailwind CSS v4**
- **TypeScript**

## Pages

| Route | Description |
|-------|-------------|
| `/` | Homepage — hero, categories, featured products, WhatsApp CTA |
| `/products` | All products with category filter |
| `/products/[slug]` | Product detail — specs, payment methods, order CTAs |
| `/about` | Store story, values, contact |

## Products

iPhone 16 Pro, iPhone 16, Samsung Galaxy S25 Ultra, MacBook Pro M4, MacBook Air M3, iPad Pro M4, Apple Watch Series 10, Google Pixel 9 Pro, Samsung Galaxy Watch 7

## Order Flow

1. Customer browses products on the site
2. Clicks "Order via WhatsApp" or "Order via Instagram"
3. Pre-filled message sent to `@gadgetsparknepal`

## Payments Accepted

eSewa · Khalti · Cash on Delivery

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy

Deploy to [Vercel](https://vercel.com) — connect this repo and it works out of the box.
